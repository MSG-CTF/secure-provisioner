# 생성·정리 진행 상태와 장애 재시도

정상 종료 대기는 작업 소유권을 유지한 채 1초 뒤 다시 확인합니다

- Gateway 경로 정리 전 Pod 종료 대기와 2초짜리 네임스페이스 정리 확인만 정상 진행으로 표시합니다
- 원격 API 권한 오류, 연결 장애, 소유권 충돌은 기존 점진 재시도를 사용합니다
- 네임스페이스가 없어진 것을 확인하기 전에는 삭제 완료나 예약 반납을 확정하지 않습니다
- 작업 lease와 Gateway 정리 이력은 재시작 후에도 기존 방식으로 이어집니다

## 문제별 종료 유예시간

Runtime의 승인 이미지 목록에 termination_grace_period_seconds를 지정할 수 있습니다

- 이미지 digest와 컨테이너별로 1~300초를 승인합니다
- 지정하지 않으면 Kubernetes 기본 동작을 유지합니다
- 참가자·스케줄러의 생성 요청에서는 이 필드를 직접 지정할 수 없습니다
- 승인된 값은 실행 명령·정책 요청·해석된 정책에 함께 보존하고 Pod 생성 시 일치 여부를 확인합니다
- Simple Note와 Daily Point의 승인 이미지에만 5초를 적용합니다
- DB와 그 밖의 이미지에는 일괄 적용하지 않습니다
- 기존 인스턴스와 저장된 명령의 직렬화·이미지 command·args·문제 코드는 바꾸지 않습니다

변경 후에는 실제 생성·접속·삭제, 정상 진행과 장애 재시도 구분, 네임스페이스 부재와 예약 반납을 확인합니다
